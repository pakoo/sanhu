一、怎么看这份稿

五个方向画的都是总览首页，用的都是你的真实持仓数据（总资产 213,261.70、 收益 +2,261.69 / +1.07%、7 只基金、债 72.3% 混 15.9% 股 8.82% QDII 2.97%）—— 只有视觉语言不同，这样对比才公平。

每个方向在四件事上做了不同取舍：信息密度（一屏塞多少）、字体（数字用什么字）、 颜色的作用（装饰还是编码信息）、形状语言（圆角/直角/线条）。

不在本轮范围：页面结构与信息架构（Tab 怎么分、每屏放什么）不动， 本轮只换皮；移动端适配另议。

Q1待你决策
选哪个方向？
五个方向的结构完全一样，改的是 static/css/style.css 这一层，不动 HTML 结构和任何业务逻辑。选定后我把整套页面（8 个 Tab + 弹窗）统一改过去。可以选一个为主、在补充里说明想借用别的方向的某一点。
Q2待你决策
涨跌用哪套颜色？
现在是红涨绿跌（国内习惯）。这件事值得单独确认，因为它会渗透进所有图表、表格、徽章，改起来牵一发动全身，定完就不该反复。
Q3待你决策
改造范围：一次全改，还是先改总览页看看效果？
全站有 9 个 Tab + 6 个弹窗 + 若干图表。不做取舍的代价：改一半会出现两套视觉并存，比不改更难看。

三、落地说明

不涉及架构变更：五个方向都只改 static/css/style.css 和少量内联样式， 不动 HTML 结构、不动 JS 逻辑、不动任何接口与数据表。
ECharts 图表要跟着调：饼图/柱状图的配色写在 app.js 里（colors 常量）， 选定方向后一并替换；V2 深色方向还需要给图表设深色背景与网格线。
字体不引入外部资源：单文件二进制不便再塞字体文件，且离线可用是硬要求， 所以只用系统自带字体栈（衬线走 Georgia / Iowan，等宽走 SF Mono / Consolas）。
本稿不涉及分享设计。sanhu 是本地运行的桌面 Web 工具（localhost），不是微信小程序， 没有分享卡片这一层；页面上是用户的真实持仓金额，本就不应该有对外分享入口。 写在这里是为了把「漏了」和「刻意不做」区分开。

一、背景与调性

为什么做这个：本工具唯一别人复制不了的东西，是它手里那份结构化的本地数据 —— 你的真实持仓明细、基金季报前十大持股、行业穿透、HS300/CSI500 的 PE 十年百分位、三层择时信号、回测曲线、决策台账、模拟盘。 外部 AI 有判断力但没有这些数；工具有这些数但不该自己下判断。 把两边接起来的那根管子，就是这一轮要做的东西。

调性：主色沿用 V3 柔和理财的 #4f46e5 靛紫（AI 相关一律用它，与红涨绿跌的行情色彻底分开）； 三个词 —— 数据可信、白话可懂、路径可执行。

本轮不做（明确划出去）： ① 工具内不调用任何 LLM API、不存 API Key、不产生 token 费用 —— 沿用「工具出料、你去问 AI、你来执行」的边界； ② 不做 AI 自动交易 / 自动下单； ③ 不做联网抓资讯喂给 AI（数据源仍只有本地库）。

七、Prompt 引擎与数据装配（架构变更）

九个场景如果各写各的，就是九份重复的取数 + 拼串代码，且「输出约束 + 工具操作地图 + 三色缺口」这套可达性保障会逐份漂移 （现在 theme_analysis.md 里写得很完整，另外三个端点一条都没有）。所以先立引擎，再铺场景。

目标结构

internal/ai/ ← 目前是空目录，本轮填满 ├── registry.go 场景注册表：id / 标题 / 需要哪些数据 / required 判定线 / 模板文件名 ├── collect.go 数据装配：按场景声明去 portfolio/risk/analysis/timing/scoring… 各 service 取数 ├── render.go text/template 渲染 + 统一追加尾部三件套 ├── gaps.go 缺口探测与三色分类（🟢可自助补 / 🟡等时间 / 🔴工具不支持） └── redact.go 金额脱敏（见 Q7） prompts/ ← 现在只有 1 个模板，扩到 9 个 ├── theme_analysis.md 已有，但渲染器没实现 ├── portfolio_checkup.md 新 ├── risk_alerts.md 新 ├── holdings_overlap.md 新 ├── rebalance_review.md 新 ├── fund_addposition.md 新 ├── selector_gap.md 新 ├── decision_review.md 新 └── _footer.md 新 · 输出约束+操作地图+缺口表，所有场景共用

统一响应契约（一个端点覆盖全部场景）

GET /api/ai/prompts/:scene ?code=012345&id=7&redact=1 → 取代现有四个各不相同的端点；旧路由保留并内部转发，不破坏已有前端 200 { "scene": "portfolio_checkup", "title": "组合体检", "prompt": "# 组合体检请求 —— 截至 2026-07-30\n……", "as_of": "2026-07-30 15:00", "chars": 3180, "included": [ {"key":"holdings","label":"持仓明细","detail":"12 只"}, … ], "gaps": [ {"level":"green","label":"3 只无季报持仓","howto":"加入关注列表，24h 内抓取"}, … ], "ready": true, ← false 时前端走 P3 数据不足态 "ready_note": "" }
为什么把 included / gaps 也返回：P1 的数据清单、P2 的三色标注、P3 的补数据按钮全部由它驱动， 前端不需要解析 prompt 正文 —— 否则每加一个场景前端都要跟着改。

十、数据边界说明

本产品是本地桌面 Web，不做分享功能（模板里的「分享设计」一节对本项目不适用，此处写明是刻意不做、不是漏写）。

但这一轮功能天然会把本地数据送出本机，边界必须写清楚：
① 工具本身不联网调用任何 LLM、不存 API Key、不产生 token 费用 —— 出去的动作 100% 由你手动复制粘贴触发；
② 送出去的内容只有 prompt 正文，弹窗里所见即所得，没有隐藏字段；
③ 一旦粘贴到外部 AI，内容即离开本机，可能被对方缓存或用于训练，删对话不保证撤回 —— 这就是 Q7 那个脱敏开关存在的理由；
④ 回填存档（R1）只写本地 sanhu.db，不上传任何地方。

十一、图片素材需求

本轮不需要出任何图。全部视觉元素用 CSS / 系统 emoji 实现：
· 场景卡图标（🩺 ⚠️ 🔍 📈 🛰️ ⚖️ 🧭 📒 🧪）—— 系统 emoji，跨平台可用，不需要设计资源；
· 数据齐备度徽章（🟢🟡⚪）与缺口三色（🟢🟡🔴）—— CSS 圆点 + 文字，不用图；
· 悬浮球（若 Q3 选含丙）—— CSS 渐变圆 + 🤖 字符；
· AI 靛紫渐变 linear-gradient(120deg,#4f46e5,#7c6df2) —— 已在 V3 令牌里，直接复用。
一条约束：emoji 只能当装饰，不能承载产品语义。 场景卡的可识别性必须由标题文字保证 —— 换个操作系统 emoji 长得不一样，靠图标认路会认错。

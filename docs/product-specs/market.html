一、背景与调性

为什么做：看全球市场关键信号（黄金/原油/美元/汇率/股指/美联储）现在要开好几个 App， 信息散、噪音大。这个板块把「今天市场发生了什么」压缩到一屏，配一块 AI 特别关注区。
调性：信号优先、克制、不劝交易 —— 只呈现数字和变化，不做投顾式解读，不推「机会来了」。
不在本轮范围：行情图表（K线/分时）、新闻资讯流、AI 信号映射到可买基金（你在前置问题里未选）、 任何交易入口。
你已拍板的范围（2026-07-29 前置问答）：
① 使用场景 = 每天看 1-2 次 → 打开时刷新 + 手动刷新按钮，不做自动轮询；
② AI 区 = 美股 AI 核心公司 + A股 AI 产业链 + AI 事件日历（未选基金映射）；
③ 宏观 = 关键少数：利率区间、下次议息倒计时、最新 CPI / 非农、10Y 美债收益率；
④ 指标家族 = 点名项之外再加 全球主要股指、国债收益率、加密货币、VIX。

六、数据链路与架构变更

【数据链路】 打开「市场」Tab（或点「刷新行情」） │ ▼ GET /api/market/global（新增） │ 后端并发抓 3 路，总超时 5 秒： ├── 新浪批量行情（商品/股指/汇率/美股/A股/VIX，一次 list= 全带上） ├── OKX 公共行情（BTC/ETH） └── 宏观数据（按 Q5 的决定：内置 or API） │ ├─ 全部成功 → 渲染 + 写入内存缓存（带时间戳） ├─ 部分失败 → 失败的组用上次缓存，卡片灰化 + 单卡重试（M4） └─ 全部失败（断网）→ 整页显示缓存 + 顶部一条「离线，数据为 X 时缓存」 【不做的】不自动轮询（你已定每天看1-2次）；不落库历史（无图表需求）； 浏览器不直连行情源（CORS + Referer 都过不去，必须后端代理）
架构变更（Gate 要求点明）：
① 新增 internal/fetcher/global.go：新浪批量行情 + OKX 的抓取与解析（新浪返回 GBK 编码 JS 变量，需转码解析；两源都必须带各自的白名单 Referer）；
② 新增 GET /api/market/global + static/js/market.js；
③ AI 名单存 user_settings（key: ai_watchlist，JSON）——不新增数据表；
④ 行情缓存放进程内存（重启即失，首次打开重新抓）——不落库；
⑤ 若 Q5 选甲：宏观数据作为内置 JSON 随版本走，发版 checklist（docs/release.md）加一行「核对宏观数字」。

七、分享设计

本稿不做分享。sanhu 是本地运行的桌面 Web 工具（localhost），不是微信小程序，没有分享卡片这一层； 市场页虽无个人持仓数据，但产品整体不设对外分享入口。写在这里是把「漏了」和「刻意不做」区分开。

八、图片素材需求

不需要出图。全部用 CSS 实现（与全站 V3 一致，无图片资源）；涨跌用颜色 + 正负号表达，不用 emoji 或图片。 公司名单只显示文字名称，不放任何公司 logo（避免商标侵权，也省去素材维护）。
